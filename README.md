# 胸囲充足率レコーダー

牛の **胸囲充足率**（測定胸囲 ÷ 日齢標準胸囲 × 100％）を、牛舎や放牧地でスマートフォンから記録・グラフ化するためのWebアプリです。インストール不要・アカウント不要で、GitHub Pages に置くだけで公開できます。

- 複数農場の管理
- 牛個体の登録（1頭ずつ、または **CSVで一括登録**）
- 現場での胸囲入力（入力と同時に充足率をその場で表示）
- 充足率・胸囲のグラフ表示、**画像（PNG）** や **CSV** での書き出し
- **オフライン対応**（電波の弱い牛舎でも、一度開けば起動できます）

---

## 指標について

胸囲充足率は、NOSAIかごしまの **叶 有斗（かなえ ゆうと）先生** が提唱された、育成牛の発育をわかりやすく評価するための指標です。

```
胸囲充足率（％） ＝ 測定した胸囲 ÷ その日齢の標準胸囲 × 100
```

100％が「日齢相当の標準」を意味し、下回るほど発育が遅れ気味、上回るほど順調と読み取れます。本アプリでは目安として次のように色分けしています。

| 充足率 | 表示 | 色 |
|---|---|---|
| 100％ 以上 | 標準以上 | 緑 |
| 90〜100％ 未満 | やや不足 | 黄（干し草色）|
| 90％ 未満 | 発育注意 | 赤（土色）|

### 日齢標準胸囲の近似式（x ＝ 日齢、単位 cm）

| 品種・性別 | 近似式 |
|---|---|
| 黒毛和種・雄 | −0.0004 x² ＋ 0.4221 x ＋ 77.555 |
| 黒毛和種・去勢 | −0.0004 x² ＋ 0.4221 x ＋ 77.555 |
| 黒毛和種・雌 | −0.0005 x² ＋ 0.4101 x ＋ 78.115 |
| ホルスタイン種・雌 | −0.0003 x² ＋ 0.3441 x ＋ 81.301 |

> **注意**
> - これらは育成期を対象とした二次近似式です。式の頂点日齢（黒毛雄 約528日・黒毛雌 約410日・ホル雌 約574日）を超えると値が減少に転じるため、その領域ではアプリ上に注意表示を出します。参考値としてご覧ください。
> - ホルスタイン種の雄・去勢の式は未定義です。胸囲の記録はできますが、充足率は計算されません。
> - 指標・係数の詳細は考案者・関係機関の情報をご確認ください。

## 使い方

1. **農場を追加** … 最初の画面の「＋ 農場を追加」から農場名を登録します。
2. **牛を登録** … 農場を開き、「＋ 牛を追加」で1頭ずつ、または「CSVで一括登録」でまとめて登録します。
3. **胸囲を記録** … 牛を開き「＋ 胸囲を記録」。測定日と胸囲(cm)を入れると、その場で充足率と日齢標準胸囲が表示されます。
4. **確認・書き出し** … 牛の画面で「胸囲充足率」「胸囲（実測 vs 標準）」のグラフを切り替え、画像やCSVで保存できます。

### CSVでの一括登録

農場画面の「テンプレート」から雛形をダウンロードできます。列は次のとおりです。

| 個体識別番号 | 名号 | 品種 | 性別 | 生年月日 |
|---|---|---|---|---|
| 1234567890 | あかべこ | 黒毛和種 | 雌 | 2024-05-01 |
| 1234567891 |  | 黒毛和種 | 去勢 | 2024/06/15 |
| 9876543210 | モモ | ホルスタイン種 | 雌 | 2024-04-20 |

- **品種**：`黒毛和種` / `ホルスタイン種`（`和牛`・`ホル` などの表記も可）
- **性別**：`雄` / `去勢` / `雌`（`オス`・`メス`・`M`・`F` なども可）
- **生年月日**：`2024-05-01` または `2024/05/01`
- 個体識別番号か名号のどちらかがあれば登録できます。
- Excel等で編集する場合は **文字コード UTF-8** で保存してください。取り込めなかった行は理由付きで一覧表示されます。

### CSVでの測定記録の入出力（Excel向け）

入力・出力ともにCSVで完結できます。各農場画面の「CSV（Excel）で入出力」から操作します。

- **測定記録の書き出し**：農場内すべての記録を1つのCSVに出力します（列：個体識別番号／名号／品種／性別／生年月日／測定日／日齢／測定胸囲(cm)／日齢標準胸囲(cm)／胸囲充足率(%)／メモ）。
- **測定記録の一括取込**：Excelで作成したCSVから測定値をまとめて登録できます。テンプレートの列は次のとおりです。

| 個体識別番号 | 名号 | 測定日 | 測定胸囲(cm) | メモ |
|---|---|---|---|---|
| 1234567890 | あかべこ | 2024-08-01 | 130.0 |  |
| 1234567891 |  | 2024/08/01 | 128.5 | 体況良好 |

- 記録は農場内の牛と **個体識別番号**（無ければ **名号**）で自動的に結び付きます。先に牛を登録しておいてください。
- 書き出したCSVをExcelで編集し、そのまま取り込み直すこともできます（日齢・標準・充足率などの列は取込時に無視して自動再計算します）。

## データの保存とバックアップ（重要）

データは **利用中の端末（ブラウザ）の中だけ** に保存されます。サーバーには一切送信されません。そのため次の点にご注意ください。

- 別のスマホ・PCとはデータが共有されません。
- ブラウザの履歴・サイトデータを消去すると失われます。

用途によって2通りの方法があります。

- **Excelで扱いたい／日々の記録**：各農場画面の「CSV（Excel）で入出力」から、牛個体・測定記録をCSVで書き出し・取り込みできます。
- **機種変更・端末間の完全移行**：右上の ⚙（データ管理）から **「全データを保存（JSON）」** を使うと、農場・牛・記録を丸ごと1ファイルに保存できます。別端末では同じ画面の「バックアップを読み込む」で復元します（JSONはExcelでは開けません）。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作成します（例：`chest-recorder`）。
2. このフォルダの中身を **リポジトリ直下** にすべてアップロードします（`index.html` が一番上にある状態）。
   - ブラウザからの場合：リポジトリの「Add file → Upload files」でフォルダ内のファイルをドラッグ＆ドロップ。
3. リポジトリの **Settings → Pages** を開きます。
4. 「Build and deployment」の Source を **Deploy from a branch** にし、Branch を `main`（フォルダは `/root`）に設定して保存します。
5. 数分後に表示される `https://<ユーザー名>.github.io/<リポジトリ名>/` が公開URLです。スマホで開き、ブラウザの「ホーム画面に追加」でアプリのように使えます。

> サブフォルダ配信（`/<リポジトリ名>/`）でも動作するよう、すべてのパスは相対指定にしています。

## 開発メモ

- 依存ライブラリを持たない素の HTML / CSS / JavaScript です（ビルド不要）。
- グラフは [Chart.js](https://www.chartjs.org/)（`lib/` に同梱、オフライン動作のためローカル配置）。
- 数字表示のフォントは Oswald（`lib/` に同梱）。日本語は端末標準フォントを使用します。
- オフライン起動のため Service Worker（`sw.js`）を使います。方式は**ネットワーク優先**で、オンライン時は常に最新ファイルを配信し、オフライン時のみキャッシュから起動します。そのため公開URLをオンラインで開けば更新は自動反映されます。大きな更新を配布したときは、念のため `sw.js` の `CACHE` 名（現在 `chest-app-v2`）の番号を上げると、古いキャッシュが確実に破棄されます。

### ファイル構成

```
index.html              画面のひな型
css/style.css           デザイン
js/standards.js         標準式・充足率の計算
js/store.js             端末内保存（localStorage）とCSV/JSON入出力
js/app.js               画面描画・操作・グラフ・書き出し
lib/                    Chart.js・フォント（同梱）
data/template.csv       一括登録用CSVの雛形
icons/                  アイコン
sw.js / manifest.webmanifest   オフライン・ホーム追加用
```
